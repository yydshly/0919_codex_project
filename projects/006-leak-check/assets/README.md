# 研究资源

`cover.png` 是本项目能力展示网页的真实浏览器截图，尺寸 1440 × 960。页面由本研究制作，不是作者线上网站或上游后端界面的截图。封面已写入项目元信息；尚未公网发布，在线演示地址留空。

数据库个人记录不保存到研究目录。网页交互与流程图全部使用虚构数据。

`understanding-map.svg` 为可编辑的中文探索全景图，尺寸 1800 × 3200；`understanding-map.png` 是同内容的高清图片，尺寸 3600 × 6400。图中汇总原始目标、库的实际能力、数据边界、邮件盘点方向、对使用者及产品开发的意义、适配状态与后续规划。图内明确区分原型与真实验证，保留暂停开发决定。

生成方式：`python projects/006-leak-check/scripts/build_understanding_map.py`。需要 Pillow 和中文字体；默认使用 Windows 微软雅黑，可通过 `MAP_FONT_REGULAR`、`MAP_FONT_BOLD` 指定字体文件。网页构建会将两份图复制到展示目录，提供大图查看与 PNG 下载。
