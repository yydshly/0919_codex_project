# 拾迹 · 邮箱账号盘点原型

**当前状态：原型保留，后续邮箱适配开发及真实账号验证暂缓。** 已有代码和模拟测试结果不等于真实邮箱验证通过。恢复后的方向与边界见[理解汇总与后期规划](product-roadmap.md)；以下使用说明保留供后续验证参考。

目标：用户输入自己的邮箱并完成授权，系统自动读取历史邮件，整理曾注册或使用的平台，并让每项判断可核对。文件导入作为备用入口。该原型是独立开发的邮件分析应用，不运行或复用 Leak Check 的数据库检索代码。

## 使用

1. 在仓库根目录执行 `python projects/006-leak-check/scripts/build_web.py`。
2. 运行 `python projects/006-leak-check/runtime/mail_service.py`，同时提供本机页面和邮箱读取接口。
3. 打开 `http://127.0.0.1:5196/006-leak-check/mail-trail/`。默认显示连接入口与空结果；可以主动点击“先体验示例”。
4. 输入支持的邮箱地址，使用邮箱生成的客户端授权码连接。自动读取收件箱并分析后，查看平台与证据，确认归属，导出 CSV。
5. 没有连接条件时，展开备用入口选择或拖入 `.eml` / `.mbox` 文件。

每次成功盘点会替换旧结果并重置确认状态；错误导入或连接失败保留旧结果。刷新后恢复未连接状态，不保留页面中的邮件结果。分批处理应逐批导出，不会自动累积批次。

## 实现

邮箱授权 → 本机服务只读获取原始邮件（或导入原始邮件文件）→ 浏览器 Worker → MIME 文本解析 → 中英文规则提取 → 发件域名映射 → 邮件去重和平台聚合 → 人工核对 → CSV 导出。

- 不需要数据库或模型 API。自动读取需要运行本机 Python 服务，并由用户在页面输入自己的邮箱客户端授权码；普通静态服务器只提供示例和文件导入。
- 目前实现 QQ/Foxmail、163、126、Yeah 的固定 IMAP 地址连接；服务商映射与授权方式不根据用户输入任意主机。仅读取 INBOX 中最新 100 / 500 / 1,000 / 3,000 封。
- 使用经证书验证的 TLS 993、只读 EXAMINE 和 BODY.PEEK，不改变已读状态。网易在支持 ID 扩展时发送真实 MailTrail 客户端标识。
- 从邮件头提取主题、发件地址、收件信息、日期；支持常见 RFC 2047、Base64、Quoted-Printable、UTF-8/GB18030 和多部分邮件。
- 文本正文优先，HTML 退化为纯文本；不把邮件 HTML 放入 DOM，不加载图片或链接，不分析附件与嵌套转发邮件。
- 明确创建账号/注册成功归为注册线索；登录/订阅状态归为使用记录；验证码和密码重置请求归为验证请求。
- 营销主题、普通订单、注册失败和回复/转发邮件不会单独认定为注册。保守规则可能漏识别，应结合原邮件核对。
- 已知名录为 12 个基础域名的映射，子域名按严格后缀边界合并。未知域名仍展示为待识别线索；名录不是对实际发信来源的认证。
- 优先按 Message-ID 去重，无 ID 时按邮件内容指纹去重。同一平台的多个收件地址会合并，不把平台数量称为账号数量。
- 只保留可可靠解析的日期；缺失或不合法时显示日期未知。最早相关邮件不是注册时间。
- 用户确认独立于自动分类；导出包含所有平台（不受当前筛选影响）、线索类型、确认状态、日期、数量、主题与识别理由，不含完整正文。

## 本地数据处理

本机服务会通过加密连接从用户授权的邮箱读取邮件，再通过本机同源接口交给浏览器分析。不使用 localStorage、sessionStorage、IndexedDB、cookie 或第三方统计。授权码与原文不写入磁盘，关闭请求日志。原文在本机服务内存中暂存，前端收到结果后请求清除；清除请求未送达时由任务十分钟清理机制回收。清空或刷新会解除页面的数据引用，不承诺操作系统级安全擦除。用户主动下载的 CSV 由用户自行保管。

页面采用 `connect-src 'self'`，仅与本机同源 API 通信。后端检查 Host、Origin 和临时请求令牌，固定服务商地址，禁止跨域读取；仅监听 127.0.0.1。所有邮件字段转义后展示，远程跟踪图片不会加载。CSV 字段执行引号转义和公式前缀防护。

自动读取限制：收件箱最近最多 3,000 封、单封 2 MB、总预算 25 MB；跳过与范围限制会显示提示，其他文件夹不在范围内。文件导入限制：每批 25 MB、最多 200 个文件、3,000 封，正文最多 250,000 字符；MIME 嵌套最多 8 层、100 部分。受限内容会给出提示。导入时仍需读取整份文件（包括其中的附件字节），只是不会分析附件。

## 尚未实现与不能推断

没有 Gmail/Outlook OAuth 接入、定时持续监测、云端账号、跨批次持久化、多账号分离或自动注销。当前本机 IMAP 连接实现完成，但未以真实 QQ/网易邮箱授权验证。网易/Foxmail 的账号安全策略和实际兼容性仍需实测。普通静态发布不包含本机服务，不能因此宣称公网版本可自动读取邮箱。

尚未以真实邮箱数据评估准确率、召回率或全部邮件格式兼容性。发件地址可能被伪造，验证请求可能由他人发起，邮件也可能缺失、已删除或来自其他人。不能把结果描述成完整注册清单或当前账号存续状态。

## 接入依据

- [QQ 官方授权码帮助](https://help.mail.qq.com/detail/106/985)：需在邮箱设置开启服务、生成客户端授权码；输入邮箱地址本身不构成授权。
- [腾讯官方邮件连接器资料](https://main.qcloudimg.com/raw/document/product/pdf/1270_46586_cn.pdf)：QQ IMAP 地址与 993 端口。
- [IMAP ID 标准 RFC 2971](https://datatracker.ietf.org/doc/html/rfc2971)：协商后使用真实客户端标识。
- [Gmail 权限](https://developers.google.com/workspace/gmail/api/auth/scopes)与 [Google OAuth](https://developers.google.com/identity/protocols/oauth2/web-server)：正式接入需要注册应用和相应权限；当前未实现。
- [Microsoft 授权流程](https://learn.microsoft.com/en-us/graph/auth-v2-user)：个人邮箱可用委托授权；当前未实现。

网易官方帮助站本次无法读取；已实现常见客户端配置并做离线验证，不将其标作当前官方文档与真实账号均已验证。
