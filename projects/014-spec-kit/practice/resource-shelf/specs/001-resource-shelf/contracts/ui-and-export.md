# UI 与导出约定

## 页面
- 添加表单：名称、GitHub 链接必填；标签以英文或中文逗号分隔；备注可空。
- 完整数量与状态数量基于完整集合，结果数量基于当前组合过滤。
- 状态切换、移除与撤销使用明确命名的按钮。
- 保存成功显示成功通知；无效输入和存储错误显示 role=alert；不清空失败输入。
- 搜索无结果显示“没有匹配的项目”，可清除筛选；全部为空显示“还没有收藏”。
- 损坏存储禁止新增/状态变更/删除，提供原始文本下载；不自动覆盖。

## 导出格式
JSON 对象：schemaVersion:1、exportedAt:ISO日期、repositories:完整 Repository 数组。
下载文件名 `resource-shelf-YYYY-MM-DD.json`，UTF-8 JSON。即使筛选结果为空仍导出全部收藏。
导出不含任何认证、浏览器环境或其他项目存储内容。不提供导入。

## 来源和边界
仅 github.com 且只有两个路径段，无用户名密码、无非默认端口；允许粘贴没有协议的 github.com 路径。只做格式检查，不验证仓库存在。
URL 的查询和片段忽略；拒绝 http 以外协议；最终链接统一 https。
localStorage 键只用 `spec-kit-repo-shelf:v1`；用户确认保存后不发送网络请求。
