# 真实演示输入

用户请求：用一个真实场景实际演示 Spec Kit 的能力。

根据当前工作区正在整理开源项目这一背景，由执行代理选定一个可立即使用的场景：

> 做一个中文开源项目收藏夹。能填写项目名称、GitHub 仓库链接、标签和备注，标记待研究或已研究；能搜索、筛选，在刷新后保留记录，并把全部收藏导出为 JSON。支持删除后撤销。提供明确的存储失败提示。采用本机使用的最小版本，不接账号或云同步。要求实际浏览器测试，并在展示网页中提供真实需求、方案、任务和验证产物。

这是为演示选定的实施范围，并非用户逐字提供的完整需求。名称、状态和本机存储等常规选项由代理采用合理默认值。

执行方式：实际运行官方 `specify-cli==1.0.9` 的初始化和辅助脚本；Codex 在本会话读取初始化生成的 SKILL.md，按其中流程产出文档、执行开发和验证。不是 CLI 独立生成软件，也没有伪装一个额外 AI 会话。
