# 005 · Y2A-Auto：YouTube 视频处理与 A/B 站发布

**获取 YouTube 视频，经过字幕识别、翻译、烧录或转码等处理后，发布到 A 站（AcFun）或 B 站（bilibili）；支持单平台或双平台发布。**

我们的理解：它围绕已有视频组织处理与发布。视频主体来自原内容，主要改变字幕、语言、编码格式及标题简介等发布信息；不是重新创作视频的生成或复杂剪辑工具。

使用方式：配置视频来源、处理服务和目标平台账号，由工具执行流程；可选择自动上传或保留人工确认。

## 实际处理顺序

以下按 `TaskProcessor.process_task` 阅读结果组织。各步骤受开关、现有文件、任务状态和检查点影响，并非所有任务都会执行所有环节。

### 1. 添加任务

手动添加链接，或由频道 / 关键词监控发现视频后加入队列。监控负责找内容，任务管理器负责执行。

输入：YouTube 链接、账号与网络配置。结果：带状态的任务。

### 2. 采集与文案

先采集视频元数据与封面；按开关翻译标题、简介，生成或应用预设标签，推荐目标平台分区。这里还未下载完整视频。

输入：原始标题、简介与封面。结果：面向目标平台的发布信息。

### 3. 文本审核

主流程可调用阿里云文本审核，检查标题、简介和标签；不通过时进入待人工审核。当前调用路径的封面检测标记为跳过，不能据此声称整段视频已经过审核。

输入：标题、简介、标签。结果：通过，或等待人工审核。

### 4. 下载视频

yt-dlp 负责获取视频及相关资源。YouTube Cookies、网络与上游站点变化会影响下载。已有阶段记录可用于跳过完成的工作。

输入：通过前置环节的任务。结果：本地视频与可用字幕。

### 5. 字幕本地化

已有字幕可进入处理；需要时通过 Whisper / Voxtral API 将语音转成带时间轴的文字，再按配置翻译、整理和质检。ASR 是识别，翻译是另一个环节。

输入：现成字幕，或视频音轨。结果：处理后的字幕与质量状态。

### 6. 烧录与转码

FFmpeg 负责字幕烧录与编码。烧录前存在质量门控：失败的 ASR 产物与已确认不合格字幕不能简单视为正常输入；实际放行取决于相关配置。

输入：视频、字幕与质量状态。结果：用于上传的视频文件。

### 7. 上传与反馈

开启自动模式时上传，否则停在准备上传。代码记录各平台上传响应；双平台部分成功后，可只重试未成功的平台。通知另走持久化队列。

输入：视频与发布信息。结果：平台上传结果、任务状态与通知。

## 底层怎样组织

- **任务编排**：Python / Flask 提供管理入口；任务管理代码维护状态、并发额度、阶段检查点与上传结果。
- **媒体处理**：yt-dlp 获取媒体，FFmpeg 处理音视频。CPU / GPU 编码能力与语音识别服务是两件事。
- **AI 接入**：本次版本的识别代码通过可配置端点调用 Whisper / Voxtral API。翻译、元信息生成和字幕质检由相应模块负责；不能把“支持 Whisper”理解为本机必须安装 GPU 模型。
- **质量控制**：字幕质量状态与烧录门控相连；“质检服务未跑成”和“明确不合格”有不同归因。质检仍不等于逐句人工校对。
- **失败恢复**：已完成阶段写入检查点；双平台上传记录分别保留，可对未成功平台补传。这是代码中的机制，不是经过压测的可靠性保证。
- **通知投递**：SQLite 的 notification_outbox 保存待发消息，后台线程投递；失败按递增时间间隔重试，达到上限后记录失败。

## 对我们有什么用

1. **自有视频跨语言发布**：把自己的 YouTube 内容处理成中文版本，再发布到国内两个目标平台。
2. **获授权的课程或访谈本地化**：将重复的下载、转写、翻译与发布准备串起来，人工重点复核术语、时间轴和发布文案。
3. **借鉴任务系统设计**：参考阶段检查点、部分成功恢复、人工审核状态和通知队列，应用到自己的内容处理工具中。

上述是基于代码能力推导的使用场景，未在本次研究中实际运行。相比研究集中的 BrightBean Studio，Y2A-Auto 更集中于 YouTube 视频处理及 A/B 站输出；两者关注点不同，也尚未验证相互集成。Video Shotcraft 等视频生成工具的产物也不能据此认定可直接输入本项目。

## 使用边界与准备

- 已确认的目标平台为 AcFun / bilibili；不能据此扩展为抖音、快手、小红书等平台发布器。
- 它围绕已有视频工作，没有在本次阅读范围中确认文生视频、复杂剪辑或配音生成能力。
- 下载与发布需要相关平台账号状态；CookieCloud 是可选的 Cookie 同步途径。
- 可用 Docker 或本地运行；磁盘、网络、FFmpeg 是媒体处理的实际条件。启用 AI / ASR / 审核时需配置相应服务，GPU 并非所有运行方式的统一前提。
- 自动模式、字幕翻译、烧录和审核分别有开关；部署完成不意味着已经走通整个流程。
- 内容检测不负责授予转载权限；使用自有或已获授权素材，并在发布前核对内容与来源。
