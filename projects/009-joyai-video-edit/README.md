# 009 · JoyAI-Video-Edit · 视频内容改写与效果展示

JoyAI-Video-Edit 以原视频或摄像头画面为基础，通过文字指令和可选参考图，持续生成编辑后的视频。它能替换视频中的人物形象、换装、转换画风、添加或移除画面内容、更换背景，也能组合这些修改。本子项目整理官方案例和底层原理，提供交互对照展示；展示网页不运行模型。

## 能力、输入与输出

| 想要改变什么 | 公开展示中的对应证据 | 需要谨慎理解的地方 |
| --- | --- | --- |
| 人物形象与服装 | 真人变擎天柱/高达、多人卡通化、羽绒服换装、参考图换装 | “换成某个指定真实人物身份”未在本站验证；参考图的身份保持仍需实测 |
| 整体风格与背景 | 水彩、手绘动画、城堡贵族场景、古装与宫殿 | 复杂背景、长镜头和快速运动的稳定性未知 |
| 增加内容与局部修改 | 红色帽子、墨镜，狗的毛色与配饰组合修改 | 小文字、图案和商品细节需要逐例检查 |
| 删除画面对象 | 官方动态案例移除了画面两侧的白猫 | 删除人物是相近任务推断；本页没有官方人物删除动态案例 |

输入是原有视频帧或实时摄像头画面，加自然语言编辑要求；部分任务再给一张参考图。输出是沿原视频时间连续生成的修改后画面，目标是保留有用的动作、构图和时间关系，同时改写指定视觉内容。它不是把输入视频按模板“套滤镜”就结束：主体、服饰、物体和背景都可能被重新生成。上游对这些效果提供案例和技术说明，但本站没有验证任意素材上的成功率。

## 效果展示

![实际展示页：官方案例、同步对比、编辑指令与观察重点](assets/cover.png)

五组官方案例：英式城堡贵族风格、水彩转换、狗的毛色与配饰、羽绒服换装、移除两侧白猫。

- 支持同步播放、暂停、从头播放、拖动进度与 0.5× / 1× / 1.5× 播放速度。
- 支持并排对照和滑动分界对照；选择案例后暂停，方便先看指令再播放。
- 每组包含官方英文指令、中文翻译、观察重点、应用场景与官方原片链接。
- 支持手机布局和键盘操作；资源加载失败时显示说明及上游查看入口。
- 官方 GIF 预览经 MP4 转码，300 × 172，时长 4.75–8.75 秒，无音轨。10 段 MP4 总计约 1.8 MB；不代表高清完整输出质量或推理速度。

## 本地运行

在仓库根目录执行：

```sh
python projects/009-joyai-video-edit/scripts/build_web.py
python -m http.server 5199 --bind 127.0.0.1 --directory web
```

打开 `http://127.0.0.1:5199/009-joyai-video-edit/`。源码在本目录 `site/`，构建结果在 `web/009-joyai-video-edit/`。构建不联网、不需要显卡、不加载模型权重。媒体文件已包含在项目中。

重新获取并转码官方预览（需 ffmpeg、ffprobe 和网络）：

```sh
python projects/009-joyai-video-edit/scripts/prepare_media.py
```

原始 GIF 缓存在根目录 `.local/joyai-showcase-media/`，不提交。固定提交来源、SHA-256、输出尺寸和时长见 [素材清单](assets/media-manifest.json)。

## 能力、原理与意义

它修改画面中的内容和外观，支持摄像头或已有视频，也支持参考图引导。它不是自动完成字幕、配音、转场、剪辑时间线的完整工作站。本页全部效果均为作者发布的示例，不能据此推断任意素材上的成功率。

工作流程：多模态语言模型读取首帧与指令；因果视频 VAE 压缩源视频与参考图；16B 扩散 Transformer 结合历史分块生成；解码输出后保留首块与最近片段的缓存。训练中的源视频锚定蒸馏与长序列优化用于缓解内容漂移；部署加入两步生成、FP8、算子融合和计算图加速。参见 [技术论文](https://arxiv.org/html/2608.03974v1)、[推理流水线](https://github.com/jd-opensource/JoyAI-Video-Edit/blob/d88456a8d3609994d15954947a3e1e9fb3444552/deploy/xvideo/models/pipeline.py)。

本地推理依赖 Python、PyTorch、CUDA 12.8、GPU、额外算子和约 51 GB 模型权重；网页静态展示不需要这些环境。官方公布：RTX 5090 32GB 在 840 × 480 下达到 24 FPS；RTX PRO 6000 Blackwell 在 1248 × 720 下达到 16 FPS；B200 在 1248 × 720 下达到约 30 FPS。数据来自 [部署指南](https://github.com/jd-opensource/JoyAI-Video-Edit/blob/d88456a8d3609994d15954947a3e1e9fb3444552/DEPLOYMENT.md)，不是本机测试结果；帧率也不等于端到端零延迟。

对我们的直接意义是先以较低成本验证电商换装、广告场景替换、内容画风探索、短视频创意和互动体验原型；对后续产品与技术的参考价值，是“原视频提供运动与构图、文字/参考图控制修改、分块生成维持实时交互”的整体方案。正式生产前，应使用自己的素材检查人物一致性、商品文字/图案、遮挡、快速运动和长时间运行。若工作主要是裁剪、字幕、配音，其直接价值有限。完整训练与数据流水线尚未发布，本页也未接入推理服务。
