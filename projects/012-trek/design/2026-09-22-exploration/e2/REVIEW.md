# E2 受控素材合成：检查范围与证据

本页说明代码可以证明什么，以及仍需人工或图像分析验证什么。E2 沿用 E1 的四点 WGS84 数据、局部投影及分区图幅；没有移动地理锚点来迁就素材。本轮不更改 V1、冻结归档或 E1 文件。

## 当前实现

`makeComposition(input, manifest, {size, fault})` 为每个主图地点分配一份 PNG。图片在方形框中等比完整显示（SVG `preserveAspectRatio="xMidYMid meet"`），方形框中心对齐原始地理锚点。图框尺寸为 60–140 px，默认 84 px。四个图幅完整保留；全域定位图只显示坐标点，不重复铺素材。

这个“图片中心”是第一轮明确选择的放置基准，尚未测量建筑接地点。透明留白或不对称构图可能使建筑主体的视觉中心不同于图片框中心，需在后续加入经人工确认的主体锚点。不能把中心对齐结果称为建筑接地点已对齐。

每份合成记录包括地点与素材编号、原图路径、原图尺寸和 SHA-256、图幅编号、放置框及其中心、原始经纬度、投影锚点。未旋转或改写原图像素。多图幅各有独立比例，不能用面板之间的像素距离推断真实地理距离。

## 自动检查

| 检查 | 能证明的范围 | 不能证明的范围 |
| --- | --- | --- |
| 原始输入与 E1 图幅比较 | 明确坐标系、地点语义，图幅及定位小图未被静默修改 | 外部数据仍然正确、真实入口、路线可达 |
| 四点完整且唯一 | 实际放置记录没有漏点或复用编号 | 图片内容一定是所标地标 |
| 素材绑定与清单快照 | 实际图片路径、素材编号、声明地点与导出记录一致 | 提示词要求被模型正确执行 |
| 图片框中心回算 | 实际放置框中心相对原始 E1 锚点的偏移不超过计算容差 | 建筑主体接地点、测量精度 |
| 尺寸与图幅范围 | 方形素材框遵守所选尺寸，未被图幅裁切 | 主体结构没有因生成而缺损 |
| 素材框交叠 | 发现保守的矩形重叠候选 | 透明部分以外的实际遮挡、主体可见率 |
| Node 文件验证 | 实际 PNG 文件字节 SHA-256 与登记值一致，文件宽高一致 | 文件授权、建筑真实性或美术质量 |
| PNG alpha 检查 | 在支持格式下独立解码透明通道，记录非透明像素包围盒 | 透明通道等于建筑主体分割 |

`auditComposition().pass` 仅表示“声明身份关系与布局检查通过”。`releaseReady` 始终为 `false`；90% 主体可见门槛、建筑外形和整体审美单独保持未测量或未核验，不被正常坐标结果掩盖。浏览器审计不读取 PNG 内容，文件字节证据来自单独运行的 `verify.mjs`。

## 故障注入

| 故障 | 实际修改 | 必须失败的检查 |
| --- | --- | --- |
| 鼓楼移东 | 图片框与其登记中心均东移 140 px，原地理锚点保留 | 图片中心相对原始 E1 锚点的回算 |
| 钟鼓楼交换素材 | 交换实际 `assetId`、`src` 与原图尺寸，不改地点编号 | 地点与素材的清单绑定 |
| 漏掉鼓楼 | 实际删除鼓楼放置记录 | 主图四点完整唯一 |
| 鼓楼放大三倍 | 以原中心放大素材框，不改地理锚点 | 所选尺寸及矩形重叠候选 |

测试还覆盖把锚点与图片一起移动、修改定位小图、伪造导出哈希、重复地点编号、正确素材编号配错误 URL、把素材放入定位小图、修改中心偏移，以及缺少素材、重复素材编号、复用图片路径、缺少哈希、非法尺寸和越界路径等输入。140 px 的正常设置也可能产生重叠，会据实报告；尺寸滑块并不保证所有值都通过。

## 运行与结果

仅检查模块合同与故障逻辑：

```powershell
node projects/012-trek/design/2026-09-22-exploration/e2/verify.mjs --unit-only
```

`--unit-only` 使用清楚标注的合成元数据测试夹具，不读取真实图片，也不写最终 `results.json`。本轮 28 项独立条件与故障测试通过。输入文件哈希锁定本轮 E1 数据版本，并将输出图幅与 E1 已落盘的布局记录比较，避免两个函数同时改变后互相证明。

真实素材齐备后运行同一脚本，不带 `--unit-only`。默认读取 `data/asset-manifest.json` 和 `../e1/data/input.json`，验证真实 PNG 后写入 [results.json](results.json)。结果包含输入及清单哈希、逐文件检查、正常布局报告、四类故障结果和待完成事项。若任何文件缺失、哈希或尺寸不符，脚本失败，不生成新通过报告。

2026-09-22 已使用正式素材清单执行：28 项单元条件通过，4 份真实 PNG 的 SHA-256、1254 × 1254 尺寸与透明声明逐一匹配；正常 84 px 合成的最大锚点偏移为 0 px，无矩形重叠，4 类故障全部检出。正式清单使用大雁塔 v2；拒收的 v1 未混入正常素材。所有图片的透明通道均已独立解码，但这仍不构成主体分割或建筑外形验收。

用于复现的 [normal-composition.json](normal-composition.json) 同步保存完整原图清单、E1 四个图幅、四个锚点与实际放置记录，其 SHA-256 纳入结果报告。此文件是可复现的合成合同，不是已经渲染的位图，也不是对 E2 全部门槛通过的声明。

素材的参考照片、提示词、生成时间和人工观察由上层清单与页面记录。生成后是否像钟楼、鼓楼、大雁塔、兵马俑，应逐图对照真实参考；通过素材编号检查不能替代这个步骤。
