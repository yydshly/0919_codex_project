## 本轮设计内容

在现有长安初见的纸色与绿色视觉风格上建立独立讨论入口，沿用真实归档截图。新设计与 V1 页面并列存在，不改写 V1 或归档。

1. 六步生成流程：可信地点、地理骨架、景观素材、受控合成、地图关联、出行引导。每步列出问题、输入、产出、验收与对应归档入口。
2. 地点关系：四个 V1 样本展示稳定地点编号、坐标含义、画面热点与未知字段；提出插画、地图、游览资料共用身份的设计。
3. 四页归档对照：导览图、地点地图、三日行程、原产品目标。可看实际截图、打开对应归档路由，或在本页嵌入归档网页。
4. 三个实验：地理布局、景观合成、从图到行动。明确待验证状态、通过条件及失败处理。
5. 技术设计正文：两条流程、责任边界、最小数据结构、坐标与画面关系、生成路线权衡和推进顺序，可在页面阅读或下载。

## 状态边界

讨论页的选项切换、归档嵌入和文档阅读已实现；真实地理数据生成城市图、完整双向地图联动和结构化票务维护仍是设计。本轮没有生成新的城市图片，也没有连接新模型或票务服务。

地点和照片元数据复制自 V1，已与冻结快照对比相同。本轮未重新核实这些旅游信息；未知票价和入口明确保留待确认。归档页面仍使用旧图，不能作为新生成方案已经地理正确的证据。

`15214` 仅提供本项目的静态研究页面；不暴露 `.local`、数据库或密钥，也没有 TREK 写入接口。`15213` 是独立的只读归档预览，路线查询受限；查看完整原能力使用 `5213`。归档内主动点击 TREK 或外部地图链接会离开归档。

## 本地使用

在仓库根目录启动设计页：

```powershell
powershell -ExecutionPolicy Bypass -File projects/012-trek/scripts/start_design.ps1
```

归档服务未运行时，另运行原归档的启动脚本：

```powershell
powershell -ExecutionPolicy Bypass -File projects/012-trek/archives/2026-09-22-v1-185446/start_preview.ps1
```
