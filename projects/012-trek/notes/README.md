## 设计与工程决策

- 使用静态页面，适配现有 `web/NNN-slug/` 汇总站点；运行无需安装前端包。
- 地图背景和京都插画使用独立编写的 SVG，不依赖外部图片、字体和地图 API。
- `core.mjs` 将计算和数据校验独立于界面；金额使用整数分，余数确定性分配。
- 示例数据通过 localStorage 保存，读取前校验；用户输入 HTML 转义；CSV 单元格处理公式前缀。
- CSS 包含桌面、平板和手机布局，提供可见键盘焦点、表单标签、原生对话框与减少动画支持。
- 原理页链接固定上游 commit，防止结论无意中跟随主分支变化。
