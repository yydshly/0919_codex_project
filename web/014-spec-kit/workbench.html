第二次实战 / 从定制需求到产品交付

把我们研究过的项目，
变成你的研究工作台。

这次交付的是一个可实际使用的本地产品：定制空间名称与关注方向，搜索和比较16个真实研究项目，保存个人判断，安排下一步行动，最后导出成果。

查看实际开发证据 ↗查看完整理解图 ↗
01 / 定制

决定空间怎样工作

填写名称、目标、关注方向与默认视图；保存后实际作用于产品，之后也可以修改。

02 / 研究

用真实项目比较

搜索能力与标签，选择2–3项并列比较，查看研究摘要、来源和个人结论。

03 / 行动

留下判断和下一步

写应用判断，改变跟进状态，添加任务与日期；完成、重开和删除均实际保存。

04 / 交付

带走可复用成果

导出完整JSON备份和Markdown研究报告；不受页面搜索与筛选影响。

Spec Kit 在哪里发挥作用？

本次实际运行官方初始化与辅助脚本，由Codex按安装生成的Skills写规格、制定方案、拆分任务、开发与核对。过程页展示这些真实文件和验收报告。

产品内的定制用于配置已实现能力，不会假装调用模型即时生成软件。截图来自独立测试数据，初次打开的个人空间由你自己定制。

本机运行说明

本页公开展示产品截图与开发证据。产品本身需要本地服务，未部署公网；本机启动后才能交互体验。

如重启电脑，在 projects/014-spec-kit/practice/research-workbench 目录运行：

python app/server.py --port 5215 --db F:/codex_project/0919_codex_project/.local/research-workbench.sqlite3

已保存的配置、结论与任务在本机SQLite中；用户数据不进入研究证据。
