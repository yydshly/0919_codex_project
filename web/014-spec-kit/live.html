Spec Kit 提供安装生成的技能、模板和检查脚本。Codex 在本次会话按这些技能写需求、制定方案、编写代码并实际测试。下面展示的文档和日志来自这次工作；成品可以直接操作。

01 / 先用一用成品

你的项目，可以现在就存进去。

在完整页面打开 ↗

建议这样试：添加项目 → 标为已研究 → 刷新成品 → 搜索后导出全部。初始的 3 个项目是可移除的示例，你新增的内容会保存在这个浏览器。

实际应用 · 可直接输入与操作打开完整页面 ↗

收藏数据仅保存在当前浏览器和站点，不上传、不跨设备同步；清除浏览器数据会影响收藏，导出可留备份。此处展示个人少量记录场景，不保证同时多标签页写入的强一致性。

03 / 实际检查结果
用操作结果说话。
测试在新建的独立浏览器环境中运行，没有操作你的收藏。先保留了“尚未实现时页面不存在”的失败基线，再验证完成后的行为；没有故意植入缺陷制造修复故事。测试通过只覆盖这里列出的范围。
