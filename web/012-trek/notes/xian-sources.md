# 西安地点与推荐内容核验

核验日：2026-09-22。数据文件：`site/xian/places.json`。

本数据包含 9 个景点与 4 家地址明确的真实餐厅。它是为“第一次来西安、两人三天、历史与美食”设计的编辑选集，不是全城榜单、实时库存或个性化机器学习评分。推荐理由、游玩时长、体力等级、标签与行程分区均为产品规划判断。duration 单位为分钟，只含停留估计，不含往返交通、排队及实时闭馆因素。

## 核验边界

- 景点信息优先使用景区官网、博物馆官网及西安市政府部门资料。陕历博区分小寨东路本馆与西咸新区秦汉馆，不能凭同一名称混排。
- 餐厅优先用商务部老字号数字博物馆与陕西档案资料核实品牌特色，再用高德具体门店页核实分店和地址。春发生南院门店使用曲江新区发布的开业地址资料与 OSM 交叉核对。
- 餐厅营业状态、排队、订位、当日菜单未实时核验，不能写成“正在营业”“已订位”。不填评分、人均价、未经验证的营业时间。
- 地图坐标用于展示地点和行程的大致空间关系，均非现场测量入口。导航时使用地点名称与地址，并由导航服务核对目的地。
- 图片字段留空，未以无授权图片代替核验内容。

## 坐标方法

运行中的原版 TREK（固定源码提交 `b98787f83698f3beee1b9a8475121c52f0caf07c`）通过真实接口 `POST /api/maps/search?lang=zh` 查询公开地点。返回的 OSM 对象使用 WGS84。所有选定对象的公开 OSM 链接均记录在 JSON 的 sources 中。

接口结果会混入同名地铁站、公交站或错误匹配门店，所以逐条选择建筑、景区范围或确认地址的对象，没有盲用第一条结果。例如“永宁门”优先结果是地铁站，实际选择 node/6817037487 城门；“西安钟楼”选择 way/254488435 建筑；“兵马俑”短查询混入交通点，改查完整名称后选择 way/71235670 博物馆范围。大唐不夜城、兴庆宫和博物馆范围点代表中心，并非入口。

同盛祥、德发长、西安饭庄钟楼店采用高德公开门店 GCJ-02 坐标，以常见 GCJ-02→WGS84 近似反偏移公式转换，用于与 OSM 底图对齐；不是官方测绘转换承诺，仍需地图服务确认入口。
