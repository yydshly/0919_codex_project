# 长安初见 · 从一张城市图走到一趟旅行

## 这次融合要解决什么

第一次到西安的人，往往先需要知道“这座城市有什么、哪些地方让我想去”，再决定如何安排。
本轮结合此前研究的“城景工坊 / 城市景点汇总 Skill”，把城市全景插画作为长安初见的主入口，让用户先看懂景观，再做出选择，最后执行行程。
复用的是旧项目的西安 V2 疏朗样稿，不是本轮新生成的图片。它用于建立兴趣和大体认识，尚未通过地理与文字验收。

## 三层表达

| 用户此时要做什么 | 页面怎样帮助他 | 这一层的边界 |
| --- | --- | --- |
| 一图认识城市 | 大幅微缩景观展示古城、城南、临潼等主题；点击画中地标继续探索 | 插画有艺术化压缩和已知方位问题，不提供距离、道路或导航依据 |
| 地点信息做决策 | 展示推荐理由、精选照片、预计停留、预约提示与资料来源；决定是否加入旅行 | 照片用于认识地点；预约状态需用户确认，不能承诺门票、营业或人流情况 |
| 真实地图执行 | 选择后按透明规则分成三天，在 OSM 地图查看 OSRM 道路路线，转到高德导航，保存到 TREK | 时长为估计；实时导航交给外部地图，保存成功以 TREK 重新读取的结果为准 |

## 一条完整的体验

看西安全景 → 点击地标 → 看详情、照片与预约条件 → 加入旅行 → 按地域和节奏生成三天安排 → 核对真实道路 → 打开高德 → 保存并在 TREK 继续管理。

图上只放与实际画面匹配的 7 个热点：西安城墙·永宁门、钟楼、鼓楼、陕西历史博物馆本馆、大雁塔、大唐不夜城、兵马俑。
热点表示“点击这幅图里的这个景观”，不把插画像素当作真实经纬度；地点详情、路线和导航继续使用本项目单独核实的地理数据。
西安碑林博物馆、兴庆宫公园及 4 家餐厅从图外补充清单进入。旧图没有画出它们，不在无关建筑上虚设热点。
图中其他景观暂作城市认识素材；没有接入详情与计划的地点，不冒称已实现可选择的完整城市景点库。

## 产品差异化与本轮范围

这次增加的是“从看见景观到决定出发”的衔接：插画帮助初访者理解和产生兴趣，地点信息帮助比较，地图与行程帮助行动。
城景工坊提供图片表达思路和已有样稿；长安初见实现可点击探索、精选内容、推荐规则及三日编排；TREK 提供旅行、地点、每日安排与数据库保存接口。
推荐与分日是本项目的透明规则，不称为 TREK 内置推荐算法或大模型个性化推荐。带父母、亲子与轻松节奏调整可沿用现有规则。
陕西历史博物馆须先确认预约；选中或生成计划不代表获得名额，未确认时展示替代安排。精选照片不作为实时开放、现场状态或实际订单的证据。
本轮不交付“输入任意城市即可自动生成可信导览图”，也未完成旧图的地理重绘；这是基于西安已有资料的本地定制体验。

## 本轮实际验证

- 7 个图上标签逐一点击，对应详情名称均正确；鼓楼加入后选择从 7 增至 8，更新行程后出现在古城当天，且旧行程摘要在重新安排前明确隐藏。
- 图外同盛祥入口显示羊肉泡馍实拍，图片标明非门店出品；查看真实位置后定位到本项目核实的门店坐标。
- 恢复默认 7 地点并保存，TREK 原版返回 trip 3，页面确认已保存；步行道路仍返回约 3.3 公里、44 分钟。
- 390×844 手机尺寸没有页面横向溢出；景观图在独立区域可滚动、放大，点击地标后展示对应详情。验证后恢复默认浏览器尺寸。
- 11 张实拍照片保存在本地，无图片热链依赖；作者、来源与许可在详情和导览侧栏可查看。
